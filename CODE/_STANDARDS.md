# 编码规范

1. 数据模型与 DOM 分离：`core.js` 不访问页面，`app.js` 统一负责交互与存储。
2. 方法、变量使用 camelCase，常量使用全大写，按职责拆分函数。
3. 对所有用户输入和导入数据执行标准化与校验；界面插入动态文本前进行 HTML 转义。
4. 所有数据变更先写入存储，成功后更新内存与视图；不得只显示“保存成功”而忽略写入错误。
5. 收藏是联系人属性，联系方式使用数组，禁止靠固定 phone/email 字段限制联系方式数量。
6. Excel 映射必须可逆，新增字段同时更新导入、导出、说明与测试。
7. UI 控件使用语义化 button、label、dialog；图标按钮有可访问名称，保留焦点样式。
8. 不写入真实演示个人信息；不把 Git 凭据放入代码、文档或提交。
9. 代码提交用 `feat:` / `fix:` / `docs:` / `test:` 前缀，描述实际完成的改动。
10. 合并或发布前运行核心测试、语法检查和关键用户流程验收。
