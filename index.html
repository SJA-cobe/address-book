Help

Manage contacts

Choose “New contact” and enter a name and at least one contact method. Add phone numbers, email addresses, WeChat, QQ, addresses, or a custom type. You can add more than one of each type.

Favorites and search

Select the star to add a favorite, then find it in Favorites. Search names, companies, notes, and all contact methods, with optional group filters. Press / to focus search.

Excel import and export

Exports include every contact in the current space, regardless of filters. Each contact has one row; multiple values of the same type use separate lines within a cell. The hidden “Contact methods JSON” column preserves custom types and line breaks. Before editing visible contact-method columns, clear the JSON cell for that row.

Preview before importing. Exact duplicates are skipped; people with the same name but different details stay separate. Invalid rows show a row number and reason. Confirm to add valid contacts without replacing existing records. Both English and original Chinese column headers are accepted.

About your data

Your data stays in this browser. It is not uploaded or synced across devices. Export regular backups before clearing browser data. Private browsing may remove your data when the window closes.

Demo and personal spaces

All demo contacts are fictional. Demo and personal spaces are stored separately. Switching spaces does not merge records, and deleting demo contacts does not affect your address book.
