# 联系人通讯录设计说明

应用界面和标准 Excel 表头使用英语，支持读取原中文数据与表头。

## 1. 需求与验收目标

依据 [作业原帖](https://bbs.csdn.net/topics/620593436) 实现浏览器通讯录。

| 要求 | 分值 | 设计实现 | 验证方式 |
|---|---:|---|---|
| 页面风格 | 10 | 深青与纸白、三栏地址簿、响应式详情 | 多尺寸实际浏览器截图 |
| 收藏联系人 | 25 | favorite 属性、星标开关、收藏列表与数量 | 开关、筛选、刷新恢复 |
| 多种联系方式 | 10 | methods 数组，支持同类型多条及自定义类型 | 多号码与自定义账号新增、编辑 |
| Excel 导入导出 | 25 | 一行一人、独立信息列、本地读取与生成 | 二进制 Excel 往返及导入预览 |
| 博客格式与链接 | 10 | 项目博客、编码规范 | 核对已发布仓库中的对应地址 |
| 实现说明、截图、分工等 | 20 | 设计文档、运行截图与个人记录 | 核对个人记录与完整运行视频 |
| 可选云部署 | +15 | 提供静态托管配置，数据仍在浏览器 | 以实际运行地址和教师判定为准 |

另外实现新增、编辑、删除、删除撤销、搜索、分组与排序，构成完整的联系人管理流程。

## 2. 信息架构与界面

桌面使用三栏：左栏切换全部、收藏与分组，中栏浏览与搜索，右栏显示已选联系人的全部信息。新建、导入和导出集中在页头；收藏既可在行尾操作，也可在详情中操作。联系人以连续列表组织，避免把一个地址簿切成大量相同的大卡片。

```text
┌───────────┬────────────────────────────────────────────┐
│ 空间与分组 │ 通讯录 / 全部联系人             本地保存状态 │
│           ├────────────────────────────────────────────┤
│ 全部联系人 │ 标题                导入 / 导出 / 新建      │
│ 我的收藏   ├────────────────────────┬───────────────────┤
│           │ 搜索、排序、视图切换    │ 姓名与分组         │
│ 工作       │ 姓名 / 联系方式 / 分组 │ 编辑、收藏         │
│ 朋友       │ 联系人列表             │ 多条联系方式       │
│ 家人       │                       │ 备注与更新日期     │
│ 未分组     │                       │                   │
└───────────┴────────────────────────┴───────────────────┘
```

在 1280px 以下，详情变为覆盖式独立面板；关闭或按 Escape 返回列表。768px 以下收起侧栏，显示横向筛选与分组选择。手机底部保留空间切换和帮助。编辑与导入用原生 dialog 管理焦点，手机详情用 inert 防止背景误操作。

主色 #06525c，底色 #f7f9f8，导航底色 #ebf0ee，选中底色 #e7f0ed。头像以姓名生成，不需要上传照片，也不使用真实人物肖像。不同联系人有稳定的头像配色，列表与详情保持一致。字体自托管，中文使用平台中文字体回退；每种状态均使用文字、形状及颜色共同表示。

## 3. 模块划分

| 模块 | 文件 | 职责 |
|---|---|---|
| 页面结构 | index.html | 语义结构、图标、表单和对话框 |
| 视觉与适配 | style.css | 色彩、字号、布局、状态、响应式和减少动态效果 |
| 数据模型 | core.js | 标准化、校验、签名、筛选排序、表格双向映射 |
| 状态与交互 | app.js | 空间切换、渲染、编辑、删除撤销、收藏与复制 |
| 持久保存 | app.js 中 loadSpace / commit | 读取与写入 localStorage、错误保护 |
| Excel 文件 | app.js 中 workbookFor / readExcel | SheetJS 工作簿读取和生成、预览、确认导入 |
| 验证 | TEST/ | 纯数据与真实浏览器验收 |

数据流为：用户操作 → 读取表单/文件 → core 校验 → 写入 localStorage → 更新内存 → 渲染。保存失败时不进入更新步骤。没有独立远程后端，属于浏览器本地应用；静态托管只提供页面和脚本。

## 4. 数据模型

```javascript
{
  id: 'UUID',
  name: '联系人姓名',
  company: '公司或组织',
  role: '职位',
  group: 'Work',
  favorite: true,
  notes: '多行备注',
  methods: [
    { type: 'Phone', value: '第一条号码' },
    { type: 'Phone', value: '第二条号码' },
    { type: 'Email', value: 'name@example.com' },
    { type: '课程账号', value: '自定义值' }
  ],
  updatedAt: 'ISO 8601 时间'
}
```

收藏嵌入联系人对象，删除联系人时自然一起删除，不会出现失效的收藏 ID。联系方式用数组，使同类号码与新增自定义类型不需要变更表结构。UUID 标识联系人，姓名允许重复，以免误把同名不同人合并。

## 5. 关键实现

### 收藏与组合查找

点击星标后通过唯一 ID 翻转 favorite，更新修改时间并保存。列表筛选同时应用关键词、收藏与分组。关键词搜索姓名、公司、职位、备注、类型和内容；空格分隔的多个词必须都匹配。姓名排序使用英语本地化比较，最近更新按 ISO 时间倒序。

### 动态联系方式表单

每条记录是类型和内容一对控件，可追加、移除；至少保留一行。自定义类型出现附加文本框。保存时清理空行、校验邮箱、限制过长内容。标准模型最多保存 50 项，足够课程场景，也避免异常输入使界面失控。

### Excel 一行一人与可逆映射

可见列分别承载姓名、公司、职位、分组、收藏、手机、邮箱、微信、QQ、地址、其他联系方式、备注。同类型多项用单元格换行表示。额外隐藏列“Contact methods JSON”保存 methods 完整结构，解决分号、冒号、地址换行、自定义类型与原始顺序的歧义。

导入优先读取隐藏元数据；外部表格没有该列时解析常见列。手动改可见联系方式前须清空本行隐藏元数据，操作约定见应用帮助和 README。所有导出值作为字符串而非公式写入；导入不执行工作簿公式。

导入分两阶段：解析后显示可导入数、重复数、错误行号和前五条预览；用户确认后添加有效记录。完全相同的联系人签名会被跳过，同名异信息则保留。原通讯录不被覆盖。

### 本地保存与数据保护

使用 `contacts-course-v1-demo` 和 `contacts-course-v1-personal` 两个存储键隔离演示和个人数据。偏好键只记录当前空间。每次变更先尝试序列化并写入，再更新内存；写入失败时反馈原因。存储内容损坏时保持原字符串，停止写入，不用空数组覆盖原数据。

多页面通过 storage 事件接收更新。如果另一个页面在当前表单编辑时修改数据，则阻止旧表单继续保存，提示刷新，以避免用旧数据覆盖新改动。

## 6. 技术边界与改进方向

当前浏览器和来源决定数据归属，不支持账号登录、跨设备同步或多人实时协作。清除站点数据会清除通讯录，用户应定期导出。未来可用远程数据库和访问控制扩展，但课程必做功能不依赖服务器。

Excel 限制为 5 MB、第一张工作表、10000 行联系人；不接受加密工作簿。手机与自定义值不强制全球号码规则，避免错误拒绝分机号或国际格式。邮箱执行基础格式校验，不验证实际可投递性。
