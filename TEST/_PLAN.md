# 验收计划

| 编号 | 操作 | 预期 |
|---|---|---|
| T01 | 第一次打开应用 | 标明虚构的演示空间有 8 位联系人，个人空间为空 |
| T02 | 新建姓名和多条联系方式 | 列表、详情与分组数量更新 |
| T03 | 编辑原有联系人 | 原记录更新，ID 不变，多条联系方式保留 |
| T04 | 点击收藏后进入我的收藏 | 星标、数量、筛选一致，刷新后仍存在 |
| T05 | 同一人添加两个手机、自定义类型 | 保存后各条内容完整显示 |
| T06 | 搜索公司、邮箱、备注，叠加收藏/分组 | 显示同时符合条件的结果 |
| T07 | 导出 Excel 并重新导入 | 一行一人；多号码、收藏、备注与特殊字符无损 |
| T08 | 导入含重复、空姓名、错误邮箱的表格 | 先预览，重复跳过，坏行有行号，确认前不写入 |
| T09 | 选择损坏或超限文件 | 提示原因，已有联系人不变 |
| T10 | 删除后撤销 | 先确认再删除，撤销恢复完整记录 |
| T11 | 刷新，切换演示和个人空间 | 正确恢复，两个空间不混合 |
| T12 | 模拟本地存储拒绝/损坏 | 不假报成功，不覆盖损坏原数据 |
| T13 | 使用含 HTML 标签的姓名 | 作为文本显示，不执行代码 |
| T14 | 切换列表和卡片、排序、复制 | 操作有反馈，结果正确 |
| T15 | 1440、1024、768、390、320 宽度 | 主流程可访问，正文不横向溢出 |
| T16 | 键盘 Tab / Escape，减少动态效果 | 焦点清晰，模态层约束焦点，可返回列表 |

自动化命令见 README。浏览器验收通过原页面控件触发动作，结果与截图见 [验收报告](../docs/验收报告.md)。完整运行视频须按 [演示录屏脚本](../docs/演示录屏脚本.md) 录制。
